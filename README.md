# LUMÉRA SKINCARE

Production-oriented Next.js campaign storefront for the LUMÉRA Glow Serum.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Product price, size, ingredient details, support details, certifications, and review data are intentionally labelled placeholders and must be replaced with verified brand content before launch. Checkout is a test-only integration surface and never processes payment.

## Image note

The supplied storyboard was not present in the repository file system, so the campaign currently uses one consistent editorial stock subject across the site. Replace the `MODEL` and `MODEL_CLOSE` constants in `app/page.tsx` with the approved, optimized storyboard frames before launch to preserve the exact campaign identity.
